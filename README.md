## 🚀 Como Executar Localmente

1. Clone o repositório:
```bash
git clone https://github.com/Anderson-OSJr/barbeariaramos-araraquara.git
cd barbeariaramos-araraquara
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

4. Build para produção (Vercel):
```bash
npm run build
```
